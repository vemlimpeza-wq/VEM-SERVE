# Vem Limpeza

Landing page cinematográfica e painel de controle de orçamentos da **Vem Limpeza** — serviço profissional de limpeza e revitalização de estofados.

## Stack

- React 19 + Vite
- Tailwind CSS v3.4
- GSAP 3 (ScrollTrigger)
- Google Sheets (backend via Apps Script)
- Vercel (deploy)

## Como executar

```bash
cd VemLimpeza-app
npm install
npm run dev
```

## Scripts úteis

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera o build de produção |
| `node setup_github.cjs` | Conecta o projeto a um repositório GitHub |
| `node update_github.cjs` | Commit e push para o GitHub |
| `npm run watch-git` | Monitor de alterações com push automático |
